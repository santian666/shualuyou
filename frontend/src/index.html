执行步骤

0 / 8
  1. 1
    通用材料校验计算 MIBIB、U-Boot、factory 固件的 SHA256 并检查文件类型。
  2. 2
    自动解锁 SSH 并完整备份软件自动调用 XMiR；必要时自动安装开发版，并下载当前设备全部 MTD 分区。
  3. 3
    设备与分区核对程序按所选机型验证设备型号和引导分区。
  4. 4
    写入 U-Boot上传后核对 SHA256，逐分区写入并回读校验。
  5. 5
    人工断电进入 U-Boot断电 10 秒，按住 Reset 通电，黄/橙灯长亮后确认。
  6. 6
    自动设置静态 IP兼容 Windows 10/11，按机型设置地址并检测 U-Boot 页面。
  7. 7
    浏览器手动上传固件软件只打开 FIRMWARE UPDATE；手动选择固件，等待 100% 并完成 Update。
  8. 8
    恢复 DHCP 并等待后台点击软件“上传完成”后自动恢复 DHCP，再检测固件后台。

请先下载并准备所选机型的刷机工具

程序默认从 EXE 同级的机型文件夹读取材料。AX9000 与 AX6000 文件严禁混用。

  • 指定解锁固件仅在当前固件不能直接解锁时使用，必须与所选机型一致。
  • SSH 一键解锁工具包必须包含 run.bat、便携 Python 及同目录脚本。
  • 机型专用引导文件AX9000 使用 MIBIB + U-Boot；AX6000 使用教程固定 FIP。
  • OpenWrt 固件文件名必须包含对应机型，禁止使用其他型号固件。
  • 当前路由器的原厂备份SSH 解锁后由本程序一键读取全部 MTD 分区并生成；其他路由器的备份不能使用。
AX9000 与 AX6000 的引导文件、固件和备份绝对不能混用。程序校验未通过时不要继续。
