# 小米路由器自动刷机助手

面向 Windows 的小米路由器辅助刷机工具，当前支持：

- 小米 AX9000（RA70）
- Redmi AX6000（RB06）

程序负责材料校验、SSH 解锁、原厂分区备份、设备与分区核对、引导分区写入、网卡地址切换和断点记录。断电、按住 Reset、观察指示灯及在 U-Boot 页面选择固件等物理操作，仍由用户根据弹窗提示完成。

> 刷写引导分区存在变砖风险。请确认型号和文件完全匹配，刷写过程中不要断电，不要使用其他设备的备份。

## 主要功能

- 自动识别 AX9000 / AX6000 及有线网卡
- 自动调用 XMiR 解锁 SSH
- 自动读取并保存当前路由器全部 MTD 分区
- 校验机型、关键分区、文件大小及哈希
- AX9000 写入 MIBIB 与 U-Boot，并进行回读校验
- AX6000 写入固定 FIP，并进行回读校验
- 自动设置静态 IP，完成后恢复 DHCP
- 自动打开 U-Boot 固件上传页面
- 危险步骤弹窗确认，物理操作完成后再继续
- 中断后记录进度，可继续上次流程或重新开始
- 支持清零刷机进度
- 日志实时显示并保存到本机

## 刷机流程

1. 检查机型专用材料及文件哈希。
2. 自动解锁 SSH，并备份当前设备全部 MTD 分区。
3. 核对设备型号及引导分区排列。
4. 写入机型对应的 U-Boot/FIP，并回读验证。
5. 根据弹窗提示断电、按住 Reset 后重新通电。
6. 自动将有线网卡设置为 U-Boot 所需静态地址。
7. 浏览器打开 `FIRMWARE UPDATE` 页面，由用户选择固件并上传。
8. 用户点击软件中的“上传完成”，程序恢复 DHCP 并等待新系统后台。

## 使用要求

- Windows 10 / Windows 11 64 位
- 使用网线连接路由器 LAN 口
- 以管理员身份运行程序，以便修改网卡地址
- 刷写期间保持电脑和路由器供电稳定
- AX9000 与 AX6000 的引导文件、固件和备份严禁混用

便携发布包已包含运行环境时，用户不需要安装 Go、Node.js、Python、SSH 或 Wails。请完整解压发布包，保持 EXE 与 `AX6000`、`AX9000` 文件夹处于同一级目录，不要只复制 EXE。

## 配套目录

```text
小米路由器自动刷机助手.exe
AX6000/
  bootloader/
  firmware/
  ssh/
  backups/
AX9000/
  bootloader/
  firmware/
  recovery/
  ssh/
  backups/
```

本源码仓库不提交路由器私人备份和大体积发布包。刷机材料应放入对应机型目录，程序会从 EXE 同级目录自动识别。

## 源码构建

项目使用 Go、Wails v2 和原生 HTML/CSS/JavaScript。

```powershell
go test ./...
wails build -webview2 embed
```

`-webview2 embed` 会将 WebView2 安装支持加入 Windows 程序，便于在新电脑上运行。正式发布时还需将两种机型的工具目录与 EXE 一起打包。

## 安全说明

- 软件不会保存输入的小米后台密码。
- 自动备份只应来自当前正在刷写的路由器。
- 引导分区写入期间程序会阻止直接关闭窗口。
- 固件校验失败、设备型号不匹配或分区排列异常时，不要强制继续。
- 操作前建议另行复制保存 `backups` 目录。
